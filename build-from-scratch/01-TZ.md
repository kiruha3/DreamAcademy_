## 3. База данных

### 3.1 Таблицы

**users**
- id serial PK, unionId varchar(255), name varchar(255), email varchar(320) unique not null
- passwordHash varchar(255), avatar text
- role enum("user","employee","partner","integrator","admin","superadmin") default "user"
- createdAt, updatedAt, lastSignInAt timestamp default now()
- indexes: email, unionId, role

**courses**
- id serial PK, slug varchar(50) unique not null, title varchar(100) not null
- subtitle varchar(200), description text, level varchar(20) default "basic", duration varchar(50)
- modulesCount int default 0, image varchar(255)
- targetRole enum("all","employee","partner","integrator") default "all"
- isPublished boolean default true, createdAt timestamp default now()
- indexes: slug, targetRole, isPublished

**modules**
- id serial PK, courseId bigint unsigned not null, number int not null
- title varchar(100) not null, description text
- moduleType enum("common","employee","partner","integrator") default "common"
- isLocked boolean default false, createdAt timestamp default now()
- indexes: courseId, (courseId, number)
- onDelete cascade для courseId

**lessons**
- id serial PK, moduleId bigint unsigned not null, number int not null
- title varchar(100) not null, description text
- lessonType enum("article","screencast","presentation","test","html") default "article"
- duration varchar(20), content json, isPublished boolean default true
- createdAt timestamp default now()
- indexes: moduleId, (moduleId, number)
- onDelete cascade для moduleId

**content json schema (Zod)**
```ts
LessonContentSchema = z.object({
  html: z.string().max(50000).optional(),
  s3HtmlKey: z.string().optional(),
  s3CssKey: z.string().optional(),
  posterUrl: z.string().optional(),
}).refine(d => !(d.html && d.s3HtmlKey), "html or s3HtmlKey, not both")
 .refine(d => d.html || d.s3HtmlKey, "one required")
```

**tests**
- id serial PK, moduleId bigint unsigned, title varchar(100) not null
- description text, passingScore int default 80, maxAttempts int default 2
- isFinal boolean default false, createdAt timestamp default now()
- index: moduleId

**questions**
- id serial PK, testId bigint unsigned not null, number int not null
- question text not null, questionType enum("single","multiple") default "single"
- options json not null (Array<{text:string, isCorrect:boolean}>), explanation text
- createdAt timestamp default now()
- index: testId

**progress**
- id serial PK, userId, lessonId, moduleId, courseId — все bigint unsigned not null
- isCompleted boolean default false, completedAt timestamp, createdAt timestamp default now()
- indexes: userId, courseId
- unique: (userId, lessonId)

**testAttempts**
- id serial PK, userId bigint unsigned not null, testId bigint unsigned not null
- score int not null, isPassed boolean not null, answers json not null
- attemptNumber int not null, completedAt timestamp default now()
- indexes: userId, testId

**certificates**
- id serial PK, userId bigint unsigned not null, courseId bigint unsigned not null
- certificateNumber varchar(50) unique not null, issuedAt timestamp default now()
- indexes: userId, courseId

### 3.2 Relations

courses → modules (1:N), modules → lessons (1:N). Через Drizzle `relations()`.

## 4. API

### 4.1 Middleware
- `publicProcedure` — без проверки
- `authedProcedure` — требует ctx.user, иначе UNAUTHORIZED
- `adminProcedure` — authed + role admin/superadmin
- `superAdminProcedure` — role superadmin

### 4.2 Auth Router (public)
- `register` — `{name, email, password}` → bcrypt + JWT cookie + localStorage token
- `login` — `{email, password}` → verify + JWT cookie
- `me` → User | null
- `logout` → clear cookie + localStorage
- `createUser` — admin only, `{name, email, password, role}`
- При регистрации: если unionId === OWNER_UNION_ID → role = "admin"

### 4.3 Course Router (authed)
- `list` — `{role?}` → CourseWithModules[]. Фильтр: targetRole === 'all' || targetRole === role
- `getBySlug` — `{slug}` → CourseWithModules | null
- `getById` — `{id}` → CourseWithModules | null
- CourseWithModules = nested query через Drizzle relations

### 4.4 Lesson Router (authed)
- `getById` — `{id}` → Lesson | null
- `getByModule` — `{moduleId}` → Lesson[]
- `getContext` — `{id}` → {lesson, module, course, nextLesson}

### 4.5 Progress Router (authed)
- `getByCourse` — `{courseId}` → Progress[]
- `completeLesson` — `{lessonId, moduleId, courseId}` → {success}

### 4.6 Test Router (authed)
- `getById` — `{id}` → TestWithQuestions | null
- `getByLesson` — `{lessonId}` → TestWithQuestions | null
- `submit` — `{testId, answers}` → {score, isPassed, attemptNumber}

### 4.7 Certificate Router (authed)
- `getByCourse` — `{courseId}` → Certificate | null
- `issue` — `{courseId}` → {certificateNumber}. Проверка: все уроки пройдены + финальный тест пройден.

### 4.8 Upload Router (authed)
- `getPresignedUrl` — `{filename, contentType, folder}` → {presignedUrl, publicUrl, key}
- folder: "lessons" | "courses" | "avatars"
- contentType whitelist: image/jpeg|png|webp|gif, application/pdf, text/html, text/css
- Limits: HTML 5MB, CSS 1MB, images 5MB
- key: `{folder}/{nanoid()}-{filename}`

### 4.9 Admin Router (admin/superadmin)

**admin.course** (`api/admin/course-router.ts`)
- `listAll` → Course[]
- `create` — `{slug, title, subtitle?, description?, level?, duration?, image?, targetRole?, isPublished?}` → Course. Slug regex `^[a-z0-9-]+$`. Проверка уникальности slug → 409 CONFLICT.
- `update` — `{id, ...fields}` → Course
- `delete` — `{id}` → {success}. Cascade удаление модулей и уроков.

**admin.module** (`api/admin/module-router.ts`)
- `create` — `{courseId, number, title, description?, moduleType?, isLocked?}` → Module
- `update` — `{id, ...fields}` → Module
- `delete` — `{id}` → {success}
- `reorder` — `{courseId, moduleIds: number[]}` → {success}. Транзакция: обновить number у всех модулей курса.

**admin.lesson** (`api/admin/lesson-router.ts`)
- `create` — `{moduleId, number, title, description?, lessonType?, duration?, isPublished?}` → Lesson
- `update` — `{id, ...fields}` → Lesson
- `delete` — `{id}` → {success}
- `reorder` — `{moduleId, lessonIds: number[]}` → {success}. Транзакция.
- `uploadHtml` — `{lessonId, htmlContent?, s3HtmlKey?, s3CssKey?}` → Lesson. Валидация через LessonContentSchema.

**admin.user** (`api/admin/user-router.ts`)
- `getDashboardStats` → {users, courses, certificates, avgScore}
- `listUsers` — `{limit?, offset?, search?}` → {users, total}
- `updateUserRole` — `{userId, role}` → {success}. Только superadmin.

## 5. Frontend

### 5.1 Router (hash mode)
Routes: /, /login (guestOnly), /courses, /course/:slug, /lesson/:lessonId, /test/:testId, /profile, /admin (requiresAdmin), /admin/courses, /admin/courses/:id, /admin/modules/:courseId, /admin/lessons/:moduleId, /certificate/:id, 404.

Guards: requiresAuth → /login, guestOnly → /courses, requiresAdmin → /.

### 5.2 tRPC Client
Vanilla client, url `/api/trpc`, transformer: superjson.
Headers: `Authorization: Bearer ${localStorage.getItem("dreamdocs_auth")}`.

### 5.3 Pinia Auth Store
- state: user, isLoading, isAdmin
- fetchUser() — trpc.auth.me.query()
- login/register — API call → localStorage token → reload
- logout — clear localStorage + cookie → reload
- Offline fallback: если backend недоступен, demo-mode из courseData.ts

### 5.4 UI-компоненты
Button (CVA: default/outline/ghost/destructive/link), Input, Textarea, Select, Badge, Skeleton, Progress, Table*, Dialog (radix), Tabs (radix), Accordion (radix).

### 5.5 Pages

**Public**
- HomePage — лендинг
- LoginPage — табы вход/регистрация, toast ошибок
- CoursesPage — карточки, фильтр по роли, skeleton
- CoursePage — детали, аккордеон модулей, прогресс. Блокировка: модуль 1 открыт, модуль N открыт если все уроки N-1 пройдены.
- LessonPage — HTML-контент (inline v-html или iframe S3), навигация, кнопка "Завершить"
- TestPage — вопросы, score, maxAttempts
- ProfilePage — профиль, прогресс, сертификаты
- CertificatePage — просмотр

**Admin**
- AdminPage — дашборд статистики
- AdminCoursesPage — таблица, поиск, пагинация, CRUD
- CourseBuilderPage — форма create/edit, валидация slug, после сохранения → модули
- ModuleBuilderPage — список модулей, drag-and-drop reorder, форма добавления
- LessonBuilderPage — список уроков, reorder, форма. HTML-секция: табы Inline / Upload. Inline: textarea → update content.html. Upload: file input (html+css) → presignedUrl → PUT → uploadHtml. Preview: iframe srcdoc (inline) или src (S3).

### 5.6 HTML-уроки
Inline: `v-html="content.html"`. S3: iframe `src="S3_PUBLIC_URL/content.s3HtmlKey"` sandbox="allow-same-origin". CSS: `<link>` для inline-режима.

## 6. Аутентификация
- JWT (jose, HS256, 7 дней) в HTTP-only cookie
- localStorage fallback: `dreamdocs_auth` token
- tRPC context читает cookie
- Password: bcryptjs hash
